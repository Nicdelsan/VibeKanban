<Steps>
<Step title="Run OpenCode">
  ```bash
  npx -y opencode-ai
  ```
</Step>

<Step title="Follow the login instructions">
  Complete the authentication flow as prompted. For more details, see the [OpenCode GitHub page](https://github.com/sst/opencode).
</Step>

<Step title="Start Vibe Kanban">
  Once authenticated, launch Vibe Kanban:

  ```bash
  npx vibe-kanban
  ```

  You can now select OpenCode when creating task attempts.
</Step>
</Steps>

## DeepSeek

Vibe Kanban runs a pinned OpenCode release (`opencode-ai@1.1.25`) because newer OpenCode 2.x versions changed the server API. DeepSeek models are available through the built-in `deepseek` provider:

- `OPENCODE:DEEPSEEK` uses `deepseek/deepseek-v4-pro`
- `OPENCODE:DEEPSEEK_FLASH` uses `deepseek/deepseek-flash`
- `OPENCODE:DEEPSEEK_PLAN` uses `deepseek/deepseek-v4-pro` in plan mode

Authenticate once with `npx -y opencode-ai@1.1.25 auth login` (choose DeepSeek), or set `DEEPSEEK_API_KEY` in the profile's environment variables.

<Note>
The pinned server uses its own config home (`<vibe-kanban data dir>/opencode-xdg-config`) so that settings written by a newer OpenCode in `~/.config/opencode` cannot break it. MCP servers configured from Vibe Kanban are stored there.
</Note>
